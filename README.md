# Nova — Rule-Based AI Chatbot

## DecodeLabs — Project 1

A simple rule-based AI chatbot built with Python. This project demonstrates control flow, decision-making logic, functions, input handling, and a continuous conversation loop.

## Requirements

- Handle greetings and exit commands
- Use `if / elif / else` logic for responses
- Run in a continuous loop
- Respond to predefined user inputs

## Features

- Multiple greeting commands
- Multiple exit commands
- Basic conversational responses
- Help command
- Python and AI responses
- Input normalization
- Empty-input handling
- Continuous `while` loop
- Modular functions
- Unique chatbot personality

## Example

```text
You: hello
Nova: Hello! I'm Nova 🤖. How can I help you today?

You: what is your name?
Nova: My name is Nova. I'm a rule-based AI assistant built with Python.

You: how are you?
Nova: I'm doing great! Thanks for asking. I'm ready to help.

You: bye
Nova: Goodbye! Thanks for chatting with Nova. Have a great day!
```

## Core Concepts

- **Control flow:** `if`, `elif`, and `else` select responses.
- **Continuous loop:** `while True` keeps the chatbot running.
- **Decision-making:** predefined rules and keyword matching determine responses.
- **Functions:** input normalization, response generation, and chatbot execution are separated for clean code.
- **Basic AI concept:** the chatbot is rule-based; it does not learn from data.
